# Team 5 — shared agents

Put reviewed copies of Team 5's agents and required supporting files here.
The [working folder](../../../02-agents/team-05/README.md) is where you develop
them; this folder is a published snapshot, not a second working source.

Include a short goal, model list, entry-point coordinator, how to run it,
what you checked and what remains untested. Use `team-05-` agent filenames.
Do not include credentials, datasets, databases, caches or generated results.
The team's coordinator can download an agreed branch/commit; they do not have
to wait for an upstream merge if they use the contributor's exact revision.

After reviewing the download, copy agent Markdown files into your project's
`.opencode/agents/` and any required skills into `.opencode/skills/`.
This submissions folder is not auto-loaded. Confirm provider access and
reopen OpenCode before running the coordinator.

Use the existing submit-work procedure, with `team-05` as the submission
folder name. Ask before publishing. Work only in your own team's folder.
Never push to the workshop's main branch or overwrite another team's files.
