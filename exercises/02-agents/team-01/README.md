# Team 1

Working area for Exercise 2c. Agree one goal using penguins, human proteins,
or your own dataset. Record your question, input, output and four specialist
responsibilities here. The genome example is the demonstration, not your target.

Keep your working definitions here, for example:

- `team-01-coordinator.md`
- `team-01-auditor.md`
- `team-01-analyst.md`
- `team-01-visualizer.md`
- `team-01-reviewer.md`

Use a different model for each role and record who owns each file. Coordinate
changes through a team fork/branch; submit only your own team's folder.
Other members need access to the team fork, or can propose PRs from their forks.

These files are not loaded here by OpenCode. Review and copy the agreed agent
files into the project-root `.opencode/agents/`; copy any supporting skills
into `.opencode/skills/`. Update coordinator delegation names and permissions
to match the team-prefixed names. Reopen OpenCode and check model access.
Do not overwrite an existing installed agent without reviewing the difference.

Publish reviewed copies in [your sharing folder](../../04-share/submissions/team-01/README.md).
Keep data, generated outputs, credentials and personal paths out of both folders.
See [Exercise 2c](../README.md#exercise-2c--a-team-of-specialists) for the handoff.
