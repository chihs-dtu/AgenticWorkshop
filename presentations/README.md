# Workshop introductions

Short, editable PowerPoints to introduce the concepts before opening OpenCode.
Each deck has six slides, with explanations and source links in the speaker notes.

| PowerPoint | Use |
|---|---|
| [Skills, agents and MCP](01-concepts.pptx) | Shared vocabulary, models, tools, permissions, and evidence |
| [Building useful skills](02-skills-exercise.pptx) | Exercise 1a: Peter's examples; 1b: skill-builder; 1c: create and test a skill |
| [Designing your own agent](03-agents-exercise.pptx) | Exercise 2a: compare instructions; 2b: build a modular agent |

The full [agent settings reference](../exercises/02-agents/README.md#agent-settings-reference)
stays in the exercise rather than on the slides. Use the
[testing checklist](../exercises/testing.md) for rehearsals and comparisons.

These are first-iteration teaching materials. The examples still need live
rehearsal with the intended models; the slides do not establish their performance.
